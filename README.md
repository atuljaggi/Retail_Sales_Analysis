# Retail Sales & Customer Analysis

## 📊 Project Overview

This project analyzes retail sales and customer data using **SQL and Power BI** to identify sales trends, customer behavior, product performance, and key business insights.

The project demonstrates an end-to-end data analytics workflow, including data preparation, SQL analysis, KPI development, interactive dashboard creation, and business insight generation.

---

## 🎯 Business Objective

The main objective of this project is to answer important business questions such as:

- What is the overall revenue and transaction volume?
- Which product category generates the most revenue?
- Which product category has the highest number of transactions?
- How does revenue change over time?
- Which age groups contribute the most revenue?
- How is revenue distributed across genders?
- What is the average order value?
- Which month recorded the highest revenue?
- How does customer behavior vary across different segments?

---

## 🔄 Project Workflow

### 1. Data Collection

Downloaded the retail sales dataset and reviewed the available columns and data types.

### 2. Data Cleaning

Checked the dataset for:

- Missing values
- Duplicate records
- Incorrect data types
- Invalid dates
- Inconsistent categorical values
- Incorrect calculations

### 3. SQL Analysis

Imported the dataset into SQL and performed business-focused analysis using:

- `SELECT`
- `WHERE`
- `GROUP BY`
- `ORDER BY`
- `CASE`
- Aggregate functions
- Date-based analysis
- Customer segmentation
- Revenue and transaction analysis

### 4. Power BI

Connected the cleaned dataset to Power BI and created:

- KPI cards
- Interactive slicers
- Monthly revenue trend
- Revenue by product category
- Revenue by age group
- Transactions by product category
- Revenue by gender
- Key business takeaways
- Reset filters functionality
- Last refreshed date

## 💡 Key Insights

Some of the key findings from the analysis include:

- **Clothing had the highest transaction volume.**
- **Electronics generated the highest revenue share.**
- **Customers aged 35–54 generated the highest combined revenue.**
- **May recorded the highest monthly revenue.**
- **Revenue was almost balanced across genders.**

> Note: These insights are based on the dataset used in this project and should not be treated as general retail industry conclusions.
